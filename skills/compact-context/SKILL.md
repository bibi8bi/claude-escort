# 压缩无用上下文

随时能用,不用等上下文快满。它跟收尾无关:**不写进度文件、不提交不推送**,用户要收尾会另说。本 skill 只干两件事:写存档 → 给命令。`/compact` 只有用户能敲,模型自己触发不了,**别说「已压缩」**。

**已经压过了就直接跳到最后一节**:摘要开头是「This session is being continued from a previous conversation」,说明用户已经粘过命令,别再写一遍存档。

## 先弄清压缩到底干了什么
- `/compact` 把**整段对话重写成一份摘要**,不是挑着删;命令后面那句话只决定摘要侧重什么。原话、报错原文、半截活的细节,在摘要里可能只剩一句转述。
- 原文不删:整段对话留在会话记录文件里(`~/.claude/projects/<项目>/<会话号>.jsonl`),压完摘要末尾会给出这个文件的路径,缺细节去那儿 grep。
- 压完会塞回:CLAUDE.md、本会话调用过的 skill 正文、最近读过的几个文件。其余的只剩摘要里那几句。
- 自动压缩和手敲 `/compact` 都一样只留摘要。手敲这条路的保险只有下面这份存档。
- 装了护航的压缩后快照钩子(`escort/scripts/post-compact-snapshot.sh`,挂法见 README「可选:长跑 hook」),两种压缩压完都会自动塞回 git 状态、进度最新一条和任务树;它只认盘上的东西,对话里的取舍照旧靠下面的存档。
- 想让它到线自己收尾、自己压缩、压完接着干,用护航的长跑(`escort/SKILL.md` 戊节),那是本 skill 的自动版;压完那一轮照样按本文件最后一节办。

## 第一步:写压缩前存档
写到本会话的临时目录(系统提示里有 `Scratchpad directory` 就用它)下的 `压缩前存档-<月日-时分>.md`;没有临时目录就问用户放哪。**只记对话里有、盘上没有的**:已提交的代码、进度文件里写过的,只写一句指向,别抄。六项逐项写,没有就写「无」:
1. **当前的活**:一句话,加上用户交代这件活的原话(原样粘,派验收官要原文)。
2. **做到哪**:做完的(提交没有、提交号)/ 改了还没验的文件 / 下一步的具体动作。
3. **刚定的取舍**:聊天里定下、还没写进任何文件的决定和理由;还在等用户拍板的问题(原样)。
4. **在跑的东西**:后台命令、子 agent、定时唤醒、监视器,各自的 ID 和用途。
5. **正在查的报错**:报错原文、关键命令和输出,只留接下来要用的那几行。
6. **接下来要用的 skill**:写名字(压完只塞回调用过的 skill 正文;写上名字,压完才知道先调哪个)。

## 第二步:起叫醒,再给用户一行命令
用户手敲 `/compact` 压完,Claude Code 通常不会自己开下一轮,得用户再发一句才动;而后台任务一结束会叫醒会话。所以给命令之前,先用 Bash 工具 `run_in_background: true` 起:`bash ~/.claude/skills/compact-context/scripts/wake-after-compact.sh <存档绝对路径>`,它见到压缩点就退出、把会话叫醒。起不来就在命令下面多给一行:压完再发「继续」。

先用一句话说存档写在哪、记了几项,再用围栏单独给一行,不换行,路径写全,其余尽量短:

```
/compact 保留:<当前活一句话>;下一步:<具体动作>;<未验的改动、待拍板,没有就省>。可丢:<已落盘或已放弃的那几段>。压完第一件事读 <存档绝对路径>
```

用户在终端里用、又只想压旧的那段时,可以提一句另一条路:`/rewind` 选 **Summarize up to here**(只压选中那句之前的,之后原样留),在 **add context (optional)** 那行填同一句保留说明。VS Code 面板里能不能用,未验。

## 压完之后第一轮
多半是 `[压完叫醒]` 那条后台任务结束把你叫醒的,不是用户发了话;照下面干,别等他。
1. 先读存档(路径在摘要里;找不到就 `ls` 本会话临时目录下的 `压缩前存档-*.md`,取最新那份)。
2. 摘要和存档里写的「做完了」都只当说法,改文件前先在盘上复核要动的那几个。
3. 存档第 6 项列的 skill,要用时重新调一次。
4. 缺细节去会话记录文件 grep,别凭摘要补。
5. 报用户一句:接上了哪件活、下一步是什么。
